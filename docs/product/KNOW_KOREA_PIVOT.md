# Almeng-E 방향 전환 초안

사용자 방향: 한국을 얼마나 아는지 확인하는 placement-test형 경험을 중심으로 삼고, 기존 경험담/통계는 Believe it or not 콘셉트의 별도 발견형 콘텐츠로 둔다. 아래 수치와 명칭은 구현 확정이 아닌 제안이다. 이 문서는 배포 승인이 아니다.

## 핵심 여정

랜딩 → 한국 지식 테스트 → 결과 카드 → 공유 또는 다시 도전.

- 핵심 CTA 제안: `How well do you know Korea?` / `Take the Korea test`.
- 1회 12문항, 3~5분을 시작점으로 제안한다. 강제 타이머는 없다.
- 음식·언어/문화·일상·역사/지리의 4영역에서 각 3문항을 뽑는 방안을 제안한다.
- 1회 내 중복 문항은 없다. 중도 이탈 전까지 진행 상태를 보여준다.
- 결과는 점수, 영역별 강약, 짧은 해설 복습을 제공한다. 오답을 모욕하거나 국적·정체성을 실제 평가하는 표현은 피한다.
- `Honorary Korean`은 가벼운 게임 칭호로 사용할 수 있다. 초기 버전은 검증된 능력평가나 실제 자격/인증이 아닌 퀴즈로 안내한다.
- 점수 구간·레벨명·합격선은 문항 난이도 검토 후 결정한다. 12문항으로 통계적으로 검증된 배치/등급을 제공한다고 주장하지 않는다.

## 별도 발견 흐름

- 기존 Reveal 8편과 통계 Quiz 7편은 `Believe it or not`에 배치하는 방향이다.
- 개인 경험담은 개인 사례로, 통계는 조사 범위를 가진 수치로 표시한다. 모든 항목을 문자 그대로 사실/거짓 이진 문제로 바꾸지 않는다.
- 이 콘텐츠는 한국 지식 점수에 합산하지 않는다. 경험담 추측은 지식 시험의 정답 근거가 될 수 없다.
- 결과 화면의 선택 CTA `Discover a little more`로 연결할 수 있다.

## 콘텐츠 준비

- 정답이 분명하고 출처로 확인 가능한 일반 상식·문화·역사·지리 항목을 별도로 준비한다.
- 문항별 영역, 난이도, 정답, 해설, 확인 근거, 시점에 따라 바뀌는지 기록한다.
- 첫 시험에 필요한 문항만으로도 테스트는 가능하지만 재도전 시 새로운 세트를 제공하려면 영역별 예비 문항이 필요하다.
- 기존 원자료 콘텐츠를 한국 일반상식으로 재분류하지 않는다. 아직 새 테스트용 문항 풀은 제작·검증되지 않았다.

## 현재 구현 상태

- main: 기존 공개 피드와 콘텐츠 15개.
- work: 이번 방문 동안 완료/열람한 콘텐츠를 기억하고 중복을 줄이는 기능. 새로고침·전체 페이지 이동·탭 종료 시 초기화한다.
- 테스트·결과·공유 화면 및 새 라우팅은 아직 구현하지 않았다. 현재 진행률 기능은 추후 테스트 진행/정답 상태 관리에 활용할 수 있다.
- 기존 흰색/검정/라임 디자인 원칙과 반응형 규격을 유지한다.

## 최신 구현 범위 조정

사용자가 랜딩 → 더미1문항 → 해설·완료 흐름을 main에 반영하도록 지시했다. 라면의 곁들임 김치/단무지를 영어로 제공한다. 12문항 시험·칭호·통계·Believe it or not 연결은 이번 버전에서 제외한다. 위의 전체 테스트 구상은 향후 제안으로만 남긴다.
