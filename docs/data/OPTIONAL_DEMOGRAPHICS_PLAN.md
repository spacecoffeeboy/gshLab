# 국가·성별·나이: 향후 선택 수집 흐름 제안

현재 화면은 이 정보를 묻거나 저장하지 않는다. 아래는 운영 전 확정이 필요한 설계 메모이며 법률 검토가 끝난 개인정보처리방침이 아니다.

## 동의와 흐름

국가·성별·나이가 언제나 각각 개인정보라는 뜻은 아니지만, 응시 식별자·답변·기타 정보와 연결되면 개인정보가 될 수 있다. 서비스에 필수가 아닌 국가/성별/연령대별 통계를 위해 수집한다면 별도의 선택 동의를 받는 방향이 적절하다. 적용 법률과 처리 목적에 따라 동의 외 근거가 성립할 수 있으므로 동의가 모든 상황의 유일한 근거라고 단정하지 않는다.

권장 위치: 응시 설정이나 정답 확인을 막지 말고 **리포트를 먼저 보여준 뒤**, 하단에서 선택 참여를 제안한다. `건너뛰기`를 동등하게 제공한다. 미동의/미응답이어도 점수·해설·재응시를 제한하지 않는다. 기본 체크를 하지 않는다.

- 목적: 국가·성별·연령대별 응시 경향 분석 등 구체적인 목적을 확정한다.
- 국가: 국적과 거주국 중 어느 정보가 목적에 맞는지 정하고 명칭을 명시한다. 거주국 기준 분석이라면 거주국가만 묻는다.
- 성별: 응답하지 않음을 허용한다. 불필요한 자유서술을 받지 않는다.
- 나이: 생년월일 대신 연령대를 우선 검토한다. 미성년자, 특히 한국에서 만14세 미만의 동의 처리와 해외 이용자에 적용될 연령 기준은 운영 전 결정한다.
- 항목, 이용 목적, 보유·이용 기간, 동의 거부권과 거부 시 영향 없음 등을 동의 전에 안내한다.
- 운영자 정보, 실제 보유기간, 삭제/철회 방법, 보안 조치, 위탁/국외이전 관계를 운영 서비스와 지역 선택 후 확정한다. 로그인 없이도 본인 기록 삭제를 요청할 수 있는 수단을 설계한다.
- Neon 등 해외 사업자나 해외 리전을 쓰면 실제 보관 위치와 계약 관계에 맞춰 국외이전 관련 요건도 검토한다.

## 공개 통계

실제 응답이 쌓인 뒤에만 집계한다. 원시 응답이나 개인 프로필을 공개하지 않으며 소수 조합의 재식별 위험을 검토한다. 이번 버전의 분야별 정답률은 한 사용자의 해당 응시 결과이지 인구통계 집계가 아니다.
