# 현재 운영: 정적 문항 + 브라우저 메모리

DB 등록·접속·서버 운영은 하지 않는다. PostgreSQL/Neon SDK와 연결 환경변수도 사용하지 않는다. 현재 출제/채점에 외부 API나 DB가 필요하지 않다.

## 데이터 흐름

1. `content/editorial/quiz-review-v2.csv`: 사용자 원고와 검토 상태를 보존한 원본.
2. `python scripts/import-quiz-csv.py`: 검토완료만 추출하고 OX의 — 표시는 제거, 선다/MCQ는 하나의 형식으로 매핑한다. 질문·실제 선택지·해설을 재작성하지 않는다.
3. `content/quiz-bank.json`: 실제 앱 문항 70개. 초급28 / 중급35 / 상급7. 정답과 해설은 브라우저 번들에 포함되므로 공식 인증이나 부정행위 방지 시험으로 주장하지 않는다.
4. `content/quiz-bank-manifest.json`: 버전과 제외한 원고 번호를 기록한다. 확인필요9개·보류3개는 출제하지 않는다.
5. React context: 응시ID, 선택한 레벨/모드, 출제 순서, 선택지와 시각을 이번 방문 중에만 기억한다. 원격 저장, localStorage, sessionStorage, 계정 저장은 없다.
6. `/report`: 같은 메모리에 있는 응시 기록으로 개인 리포트를 만든다. 새로고침·탭 종료 시 결과가 사라진다. 직접 접속한 리포트에는 가짜 점수 대신 재응시 안내를 보여준다.

## 출제·채점

- 사용자가 고른 레벨에서만 중복 없이 무작위 추출. 초급/중급15개, 상급7개. 부족한 문제를 반복해서15개로 만들지 않는다.
- 문항당1점. 미응답은 정답 수에 포함하지 않고 별도로 표시한다. 분모는 실제 출제 수다.
- 결과는 초급14/15, 상급7/7처럼 레벨을 항상 붙인다. 다른 레벨의 점수와 같은 척도로 환산하지 않는다.
- 일반 모드는 시간 제한 없음. TIME ATTACK은 시험 전체300초, 해설 열람 중에도 계속 흐름. 실제 시각 차이로 계산하며 창 비활성화 후 복귀 시에도 만료를 확인한다.
- 처음 답변만 인정. 선택 즉시 체크와 짧은 성공 모션, 해설은 아래 펼침. 리포트는 모든 문항의 내 답/정답/해설과 해당 출제 분야 결과를 표시한다.
- 현재 한국어만 제공. 영어 버튼은 비활성화하며 임의 번역하지 않는다.
- 난이도와 해석 문구는 편집 기준이다. 실제 정답률·난이도 보정·전국 순위·백분위·다른 사용자 평균을 만들지 않는다.

## DB는 설계만 준비

`db/schema-draft.sql`은 실행하지 않은 PostgreSQL 설계 초안이다. 빌드/배포에서 실행하는 스크립트가 없다.

- 문항 버전과 선택지
- 익명 응시 시도와 선택 레벨, 실제 출제 수, 모드, 시각
- 중복 없는 출제 문항과 당시 문항 스냅샷
- 실제 고른 선택지, 최초 응답 시각, 스냅샷 정답에 따른 채점
- 향후 별도 선택 동의 후에만 넣을 인구통계 항목

향후 연결할 때 서버 API에서 응시 접근 토큰 검증, 실제 출제 수 검증, 최초 답변 고정, 서버 기준 마감 시간, 문항/선택지2~3개 검증, 문항 버전 불변성, 동시 제출 처리, 보유기간 만료 삭제를 함께 구현·검증해야 한다. 현재 SQL만으로 그 운영 기능이 완성됐다고 보지 않는다. 사용자 답변용 운영 DB는 아직 없다.
