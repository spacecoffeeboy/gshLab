# Almeng-E — 영상 대사 기반 수치형 디자인 원칙

## 범위와 근거 구분

사용자가 첨부한 `video1_text.txt`–`video4_text.txt` 네 대사를 읽고 정리했다. 원본 영상 화면/URL은 제공되지 않았고 자동 추출 대사에는 오탈자·숫자 인식 오류가 있을 수 있다. 아래 타임스탬프는 **제공된 대사** 기준이다. 디자이너의 예시를 모든 서비스에 통하는 규정이나 실제 측정 실험 결과로 확대하지 않는다. 발언자의 신원·전문성에 대한 별도 검증을 했다고 주장하지 않는다.

- **[직접]**: 대사에 수치나 원칙이 명시됨. 절대값이 아니라 예시라고 한 맥락까지 보존한다.
- **[적용]**: 해당 취지를 이 앱에 맞게 구체화한 우리의 선택. 영상 발언으로 인용하지 않는다.
- 스타일만 재현하지 않고 검색 → 선택 → 공개 → 출처 → 다음의 전체 흐름을 확인한다.

## 2. Almeng-E 적용 계약 — 아래 값은 우리의 구현 기준

|---|---|---|
| 읽어야 하는 본문·해설·선택지 | **15px / 1.6행간 / 400** | V1의 14–16 출발 범위. 영어 장문에는 1.6을 적용하는 별도 판단 |

| 데스크톱 페이지·문항 제목 | **28px / 1.2 / 600** | 넓은 화면의 가독성. 카드/결과 제목24px |

### 라임 사용

헤더 AL 마크, 히어로의 `deeper`, 선택 상태의 옅은 라임 면이 중심이다. 피드의 종류·모든 태그·매번 나오는 카드 배경을 각각 채색하지 않는다. Quiz 정답의 초록은 장식 색이 아닌 의미 전달이며, 피드백 문구와 함께 사용한다. Reveal에는 정오 색을 적용하지 않는다.

### 저장 기능 제거 범위

Saved 탭, 하트/저장 버튼, 저장 개수, localStorage 읽기·쓰기, 저장 관련 토스트, 랜딩의 저장 약속을 제거한다. 이전 localStorage 값은 사용하지 않되 사용자의 브라우저 데이터를 임의로 지우지는 않는다. 향후 로그인 여부와 저장 기능은 별도 제품 결정이다.

| 이전 상태 | 보완 |

| 브라우저 글꼴에 따라 표시가 달라지는 기호 아이콘 | 동일 viewBox·stroke의 SVG 내비게이션/화살표 |

| 랜딩·문서에 저장 기능 약속 잔존 | 현재 흐름과 맞도록 수정 |
| 정답/Reveal 공개가 화면 하단에 생겨 키보드로 찾기 어려움 | 공개된 결과 제목으로 포커스·가까운 스크롤 이동 |

## 4. 검증 방법과 완료 판정

- `npm test`: 콘텐츠 검증, 비게시 차단, 검색, 토픽, Quiz/Reveal, 중복 없는 랜덤, Saved/저장 버튼 부재.
- `npm run build`: 현행 콘텐츠 검증+프로덕션 Next.js/TypeScript 빌드.
- `npm run test:browser`: 실행 중인 로컬 앱에 연결. 반응형·키보드·조작 영역·실제 계산된 폰트·입력 높이·간격·콘텐츠 겹침·파비콘·개발 예시와 공개 피드 분리를 측정.
- 브라우저 테스트는 폰트 로드 후 캡처하며 결과는 ignored `test-results/`에 저장한다. 실제 원고/이미지의 권리·사실 여부는 검증하지 않는다.
- 200% 글자 확대는 브라우저에서 테스트 요소의 본문/컨트롤 font-size를 두 배로 설정해 레이아웃을 확인하는 **스트레스 테스트**로, OS 글자 확대나 실제 기기 검증과 동일하다고 하지 않는다.
- 실제 스마트폰의 손가락 편의·OS 설정은 물리 기기가 없어 미검증임을 구분한다.
- 공개 콘텐츠0개가 정상이며 미검증 예시는 계속 `/preview` 개발 모드에만 있다. 화면을 채우려고 임의 게시하지 않는다.
