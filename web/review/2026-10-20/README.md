# Malang 콘텐츠 검토 안내

> 이전 v1 초안입니다. 최신 검토 자료는 [HWP 참조 일상 대화 각색 v2](../2026-10-20-hwp-v2/README.md)를 사용하세요. v2는 60문장이고, 기존 목표 300문장 중 240문장이 남아 있습니다.

기준 커리큘럼: dialogue-300-v1

- **sentences-300.csv**: 한 행이 한 학습 문장입니다. 전체 300문장, 3개 난이도, 난이도마다 10세트 × 10문장입니다. 대화, 한영 문장, 보기, 정답, 빈칸별 정답 해설을 함께 수정합니다.
- **sets-30.csv**: 30개 세트의 제목과 구성을 검토합니다. 세트 제목 수정은 이 파일에 해 주세요. 문장 CSV의 세트제목_참고는 현재 제목을 보여 주는 참고 컬럼입니다.

## 편집하기

1. Excel 또는 Google Sheets에서 CSV를 엽니다. 한글 호환을 위해 UTF-8 BOM과 CRLF로 저장했습니다. 필요하면 UTF-8로 가져오고 열 형식을 텍스트로 지정하세요.
2. 문장ID, 세트ID와 헤더 이름은 유지하세요. 행은 정렬해도 됩니다. 난이도/세트 이동을 원하면 검토메모에 적어 주세요.
3. 검토상태는 미검토 / 수정완료 / 승인 / 보류 중 편한 값으로 바꾸세요. 문장 자체를 고치거나 검토메모로 수정 방향을 적어도 됩니다. 기본값은 모두 미검토입니다.
4. 빈칸문장의 {{1}}, {{2}}, {{3}}은 각각 해당 빈칸의 정답을 넣는 위치입니다. 예: 팀장님{{1}} 식사하{{2}}? → 정답 은 / 셨어요. 번호는 각 1회씩 사용하고 유지하세요.
5. 정답을 바꾸면 해당 보기 3개 중 하나와 정확히 일치시켜 주세요. 빈칸문장에 정답을 넣은 결과는 학습문장_한국어와 일치해야 합니다. 학습대상 Y인 대화 문장의 한영 내용도 함께 맞춰 주세요.
6. 빈칸수는 2 또는 3입니다. 사용하지 않는 세 번째 빈칸 컬럼은 비워 둡니다. 대화는 2~3개, 학습대상 Y는 정확히 1개로 유지하세요.
7. 해설·힌트·뜻은 영어 원어민 학습자에게 보여 줄 영어 텍스트입니다. 한국어로 수정 방향만 주고 싶으면 검토메모를 사용하세요. 종합해설은 문장 전체의 맥락이고, 빈칸N_정답해설_영어는 각 선택의 근거입니다.
8. 수식으로 오인될 수 있는 -, +, =, @로 시작하는 셀은 앞에 작은따옴표를 붙여 텍스트로 보호했습니다. 다시 반영할 때 이 보호 문자만 제거합니다.
9. 수정한 CSV 두 개를 그대로 다시 올려 주세요. 한 파일만 검토했다면 그 파일만 보내도 됩니다. 문장ID 기준으로 변경 내용을 비교한 뒤 앱에 반영할 수 있습니다.

## 현재 해설의 상태

현재 앱에서 사용 중인 빈칸별 영어 해설을 그대로 내보냈습니다. 누락된 해설은 없지만, 일부는 공통 문형 설명을 공유하는 초안입니다. 이 파일의 미검토 상태는 언어 전문가의 검수를 완료했다는 뜻이 아닙니다.

원본 파일은 보관하고 사본을 수정해 주세요. 내보내기 명령은 비어 있지 않은 폴더를 덮어쓰지 않습니다.
