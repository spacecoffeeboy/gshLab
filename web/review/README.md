제공된 부산행 HWP의 발화 기능을 참고해 일상 대화로 새로 각색했다. 원문 직접 인용본이나 Korpora 추출본이 아니다. 하·중·상 각 20개이며 기존 목표 300개까지 240개가 남아 있다. 실제 앱에 반영하기 전 검토용이다. 원본 HWP와 추출 원문은 이 저장소에 포함하지 않는다.

## 이전 v1

`2026-10-20/`과 `malang-review-2026-10-20.zip`은 공통 문형을 반복한 기존 300문장 초안이다. 사용자가 품질 문제를 지적한 이전 버전이며, 새 검토본과 합치지 않는다. 새 검토에는 위 v2 파일을 사용한다.
