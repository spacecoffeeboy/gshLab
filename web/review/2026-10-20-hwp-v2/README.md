## 출처와 중복

원본 파일명은 부산행.hwp이며 SHA-256은 e461ec1cc29f43fbbfe1cf6731bbd35078eb94201c95c768859a45fcfa47869e입니다. 제공 문서의 표제에는 시나리오 2015. 3. 2, 감독 연상호가 표시돼 있습니다. 원문참조문단은 HWP에서 추출한 비어 있지 않은 문단을 순서대로 1부터 센 번호입니다. 원문참조장면은 장면 제목을 기준으로 순서대로 붙인 S번호입니다. 원본 HWP의 페이지 번호가 아닙니다.

동일한 원문 참조 문단을 여러 문제에 재사용하지 않았습니다. 다만 **서로 다른 문단이 같은 영화 장면에 속하는 경우는 있습니다**. 60개의 서로 다른 원문 장면에서 추출했다고 주장하지 않습니다. 실제 원문 장면 수와 공유 목록은 보고서에 공개했습니다. 각색 대화/학습 문장의 정규화된 정확 중복은 없고, 3-gram Jaccard 0.55 이상의 쌍은 없습니다. 의미상 유사함까지 자동으로 보장하는 검사는 아닙니다.

## 수정해서 돌려주기

CSV는 UTF-8 BOM과 CRLF 형식입니다. Excel/Google Sheets에서 편집하고 CSV로 저장해 주세요. 문장ID, 세트ID와 열 이름은 유지하세요. 검토상태/검토메모를 사용하거나 대화·문장·보기·정답·해설을 직접 수정해도 됩니다. 맨 앞 작은따옴표는 수식 오인을 막는 텍스트 보호 문자이며 반영 시 제거합니다.

빈칸문장의 {{1}}, {{2}}는 해당 번호의 정답이 들어갈 위치입니다. 정답을 넣은 결과와 학습문장_한국어, 학습대상 Y인 대화 문장을 일치시켜 주세요. 정답은 보기 중 하나여야 합니다. 새 문장이 문맥상 복수 정답을 허용한다면 검토메모에 표시해 주세요.

두 CSV를 수정한 뒤 채팅에 올려 주시면 됩니다. 기존 2026-10-20 폴더의 300문장 CSV는 이전의 반복 문형 초안이고, 이번 자료와 합치지 않았습니다.
